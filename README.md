This is a place to publish incremental work on the Central ECU Multi-Level Modeling case study. 

It provides a 'sandbox', where you can play with the DMLA, SysMLv2, and the DMLA-to-SysMLv2 mapping. You have two options to enter the sandbox, via the Microsoft Dev Containers VS Code extension or GitHub codespaces.

Microsoft Dev Containers
Install the official dev-containers extension from VS Code marketplace.

With the plugin installed, VS Code will prompt the user to reload the sandbox in the dev container, or the Dev Containers: Reopen in Container can be used to load the sandbox within the container.

GitHub Codespaces
Accessible directly on the cloud in a web view of GitHub via the upper-right green  <> Code menu item - choose Codespaces instead of Local.

Alternatively you can can use the remote access to Codespaces from your local VS Code installation via the official extension VS Code marketplace.
